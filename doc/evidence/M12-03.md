## 安全与失败语义

- 请求只发送去标识后的消息；测试确认手机号和邮箱原文未进入供应商请求体。
- 429、5xx、坏 JSON和超时每次都只产生一次 HTTP 请求，避免自动重发可能计费的调用。
- 429保留数字型`Retry-After`秒数；5xx异常不包含供应商响应正文。
- `prompt_tokens`、`completion_tokens`和`cached_tokens`缺失或不可解析时保持`null`，不伪造为0。
- 缺少服务端 Key 时在网络访问前失败；Key只用于后端 Authorization 请求头，未写日志、响应或客户端源码。
