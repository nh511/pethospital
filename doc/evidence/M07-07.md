# M07-07 改期申请与历史验收记录

日期 2026-11-09。结论通过。

## 已实现范围

- MINI 主人和对应有效 WEB 医生可以创建改期申请。两端提供稳定历史分页，管理员可读取历史。创建要求 version、幂等键、同医生的不同未来时段与非空原因。
- 创建按医生、宠物、时段 ID 升序、预约、改期申请的顺序加锁。申请只写独立 OPEN 记录，原预约、旧时段占位和新时段占位均保持原值。
- 有效期取提交后24小时、原时段开始、新时段开始和适用的确认截止中的最早值。新建前在锁内清理到期的 OPEN 标记，并发只允许一条 OPEN。
- 创建返回201，历史按创建时间和数值 ID 降序。幂等重放返回原申请。
