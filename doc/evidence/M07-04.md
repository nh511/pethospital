# M07-04 医生确认和拒绝验收记录

日期 2026-11-09。结论通过。

## 已实现范围

- 对应有效 WEB 医生可通过 `POST /api/v1/staff/appointments/{appointmentId}/confirm` 和 `/reject` 处理 PENDING 预约。动作要求 version 和幂等键，拒绝另需原因。
- 确认检查截止和开始时间，保留原名额。拒绝释放一次并记录原因。事务按医生、宠物、时段、预约、改期申请的顺序加锁并复核范围。
- 确认和拒绝都使 OPEN 改期失效，写入状态轨迹、审计和主人通知。并发确认和拒绝仅一个成功，同键重放恢复原结果。
- 联合回归同时核验医生宠物、共用健康日志和预约分页的 `total` 按已冻结契约输出 JSON 数字，长 ID 继续使用字符串。
