# M04-05 下载票据与未绑定清理验收

日期：2026-10-31。结论：通过。下载授权和丢弃操作均在真实 MySQL 8.4.13 与项目 SeaweedFS 4.51 上完成验证；签名 URL、S3 凭据和对象键未进入审计或测试报告。

## 实现范围

- `server/src/main/java/com/pethospital/shared/FileController.java`、`FileDtos.java`、`FileService.java`：实现 `POST /api/v1/files/{fileId}/download-ticket` 与 `POST /api/v1/files/{fileId}/discard`。
- 下载绑定文件时必须提交与 `file_binding` 完全一致的 `businessType/businessId`，并按宠物、健康日志、病历草稿/版本、知识版本、指南、资质或头像重新校验当前对象范围；未绑定文件仅上传者可预览。
- 下载票据固定为 60 秒，只在响应返回 URL；审计仅保存过期时间，不保存签名 URL 或对象键。
- 丢弃仅允许上传者删除尚未绑定的 `READY` 文件；对象存储删除成功后才把元数据标为 `DELETED`。操作接入事务型幂等执行器，同键同参数重放原结果且不会二次删除对象。
- `tools/openapi-contract.mjs`、`doc/openapi.yaml`、两端生成类型及 `M0206ContractTest`：两个操作标为 `IMPLEMENTED`，使用封闭请求/响应 schema。
- `server/src/test/java/com/pethospital/M0405IT.java`：5 组真实场景覆盖私有对象签名读取、精确绑定、跨用户与 30 天授权过期、丢弃幂等、历史附件保护和存储失败恢复。
- `tools/run-maven.ps1`：增加显式 `-LoadDotEnv`，仅向 Maven 子进程加载本地 `.env`，不回显值并在执行后恢复原进程环境。
