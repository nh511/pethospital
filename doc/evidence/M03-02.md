日期：2026-11-02。结论：实现、普通测试及真实 MySQL 集成验证已完成，任务暂不勾选。真实微信 code 换取 OpenID 仍缺 AppID/Secret，不能伪造通过。

## 已实现范围

- `WechatIdentityAdapter` 及配置支持 `disabled`、`stub`、`real` 三种互斥模式；默认关闭，真实模式只从服务端配置读取 AppID/AppSecret并请求 `jscode2session`。
- 客户端 DTO 只接受临时 `code` 和隐私政策版本；未知 `openId` 字段由严格 Jackson 配置拒绝。
- OpenID 使用独立服务端密钥生成 HMAC-SHA256 查找值，并以带版本、随机 IV、AAD 和认证标签的 AES-256-GCM 密文保存；响应、审计和普通错误不返回 OpenID、密钥或微信错误明细。
- 首次登录原子创建无密码 USER、绑定角色和隐私同意；唯一键冲突路径复用同一账号；停用账号拒绝。会话、JWT、refresh哈希及 `AUTH_LOGIN` 审计复用既有事务内签发逻辑。
- OpenAPI 将 `POST /auth/wechat/login` 标为 IMPLEMENTED，并增加严格 `WechatLoginInput`；微信无用户名账号的 `UserView.username` 明确可空。
