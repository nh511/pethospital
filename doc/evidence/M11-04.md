# M11-04 按 token 分块与 profile 指纹验收

日期 2026-11-10。结论通过。

- 内部 `POST /internal/chunks` 使用固定 BGE tokenizer，按正文 320 token 和 48 token 重叠切分，按偏移量切取原始文本。每段重新分词，核对正文、特殊 token 及 MySQL `TEXT` 字节限制。
- 每段包含序号、原文字符与 token 范围、实际 token 数及 UTF-8 SHA-256。固定 profile 包含模型 revision、维度、前缀、归一化和 splitter 配置，指纹为 `282583d976e07fd471f4701e15d20d0b15420790d84a3540bbc190686f3e1307`。请求只能提交正文，分块策略由服务版本决定。持久化及同版本拒绝覆盖由 M11-06 验收。
