# M03-08 账号启停与密码重置验收证据

日期：2026-10-30。状态：**已通过最终验收并勾选**。账号停用、启用、管理员密码重置、未终结预约保护、最后有效管理员保护、幂等/version、会话撤销、冻结契约和真实 MySQL 8.4.13 集成测试均已通过。

## 已实现改动

- `AdminAccountLifecycleService.java`、`AdminAccountLifecycleDtos.java`：实现管理员账号停用、启用和密码重置。三个动作均校验账号 version 与 `Idempotency-Key`，成功后递增账号 version/tokenVersion、撤销未撤销会话并写安全审计。
- 密码重置使用既有 BCrypt 编码器；临时密码只参与内存中的 BCrypt 和请求摘要，不进入响应、审计、普通日志或测试报告。UTF-8 超过 BCrypt 72 字节边界时明确拒绝。
- `UnfinishedAppointmentQuery.java`、`JdbcUnfinishedAppointmentQuery.java`：以预约领域接口查询并锁定账号作为主人或医生关联的 PENDING/CONFIRMED/IN_CONSULTATION 预约，不依赖预约 Controller。
- 停用账号在存在未终结预约时返回 409 `UNFINISHED_APPOINTMENTS`，响应 data 含 `pendingCount`、`ownerPendingCount`、`doctorPendingCount`；移除 DOCTOR 角色复用同一领域查询并返回医生待处理数。
- `AdminUserController.java`、`SecurityConfig.java`：新增三个 POST 端点，要求 WEB audience、ADMIN 角色和数据库 `admin:users:manage` 动作权限；响应使用 `Cache-Control: no-store`。
- `BusinessException.java`、`ApiExceptionHandler.java`：业务异常可携带结构化 data，统一错误 Envelope 可返回待处理数量等冲突信息。
- `tools/openapi-contract.mjs`、`doc/openapi.yaml`、`doc/api-coverage.md`及两端生成类型：三个 M03-08 操作改为 IMPLEMENTED，新增严格启停/密码重置输入与生命周期响应 schema；运行时 Springdoc 精确子集扩至24个操作。
- `M0308IT.java`建立五组真实 HTTP/MySQL 断言，不使用 H2、空测试、全 mock、禁用或跳过。
