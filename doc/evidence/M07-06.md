# M07-06 开始诊疗和爽约验收记录

日期 2026-11-09。结论通过。

## 已实现范围

- 有效接诊医生可对 CONFIRMED 预约执行 `POST /api/v1/staff/appointments/{appointmentId}/start` 和 `/no-show`。两者要求 version 与幂等键，爽约另需原因。
- 开始诊疗写入 `started_at`。人工爽约遵守宽限时间并保留历史占位。两种动作沿用固定锁序、轨迹、审计和 OPEN 改期失效处理。
- 读取可用动作与写操作共用状态机配置。提前开始默认15分钟，爽约宽限默认30分钟，分别由 `appointment.early-start-minutes` 和 `appointment.no-show-grace-minutes` 设置。
- 用非默认10/40分钟验证窗口。开始诊疗与主人取消并发时仅一方成功。待确认超时扫描仅处理 PENDING。
