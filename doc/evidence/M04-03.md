# M04-03 安全上传与元数据验收

日期：2026-10-31。结论：通过。真实集成验证使用 MySQL 8.4.13 与项目 Compose 中的 SeaweedFS 4.51；未使用 H2、内存对象存储、空测试或全 mock 冒充验收。

## 实现范围

- `server/src/main/java/com/pethospital/shared/FileController.java`、`FileService.java`、`FileDtos.java`：实现 `POST /api/v1/files` multipart 上传和 `GET /api/v1/files/{fileId}` 元数据查询；按 MINI/WEB、USER/DOCTOR/ADMIN 与文件用途限制上传，使用真实内容哈希参与写幂等，响应不包含对象键。
- `server/src/main/java/com/pethospital/shared/FileContentValidator.java`：使用 Apache Tika 4.2.0 识别实际类型；JPEG/PNG 经 ImageIO 解码与重编码，移除 EXIF/尾随内容并限制字节、尺寸和像素；PDFBox 3.0.8 校验 PDF 可解析、未加密、页数受限，并拒绝活动动作、脚本、嵌入文件、XFA 等危险结构。
- `server/src/main/java/com/pethospital/shared/ObjectStorageAdapter.java`：增加对象删除能力，供上传事务失败时补偿清理；不向客户端公开对象键。
- `server/src/main/resources/application.yml`、`SecurityConfig.java`、`ApiExceptionHandler.java`：限制 multipart 请求体，纳入 Bearer 鉴权，并统一映射缺少 part、超限及内容拒绝错误。
- `server/src/test/java/com/pethospital/shared/FileContentValidatorTest.java`：5 组纯规则测试覆盖图片重编码、扩展名伪造、可执行伪装、正常/活动 PDF 及大小限制。
- `server/src/test/java/com/pethospital/M0403IT.java`：7 组真实 MySQL/S3 场景覆盖 HTTP multipart、鉴权、幂等、状态流转、对象字节、用途权限、绑定授权与严格响应。

上传先写入 `QUARANTINED` 元数据，验证通过后写私有 S3 并转为 `READY`；内容拒绝转为 `REJECTED` 且不写对象。失败结果可按同一幂等键重放；同键不同内容返回冲突。实现只提供有限的格式与危险特征校验，未声称具备完整杀毒能力。
