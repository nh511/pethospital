## 实现范围

- 新增 `GET/POST /api/v1/staff/health/standards` 与 `GET/PATCH /api/v1/staff/health/standards/{standardId}`。
- WEB 医生和管理员可读；只有具备有效 ACTIVE 医生资料的 WEB 医生可创建、编辑，管理员和普通用户不能写。
- 创建由服务端按当前身份关联 `editorDoctorId`，状态固定为 `DRAFT`；POST 使用全局 `Idempotency-Key`，重放不重复建标准或审计。
- PATCH 使用完整专业输入和乐观锁 version；编辑任何状态的标准都会回到 `DRAFT`，记录当前编辑医生并追加前后快照审计，等待管理员重新发布。
- 年龄上下界必须成对且有序，但两者同时为空表示未知年龄；数值参考上下界同样必须成对且有序。物种、指标、单位、说明、适用条件和来源均使用严格DTO与长度/代码格式约束。
