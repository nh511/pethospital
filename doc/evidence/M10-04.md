# M10-04 急症规则启用、停用与预览验收记录

日期：2026-11-03。结论：通过。

## 已实现范围

- 新增 `POST /api/v1/staff/triage-rules/{ruleId}/enable` 与 `disable`：仅WEB管理员可操作，均校验 `Idempotency-Key`、version和当前状态；启用只接受APPROVED规则，停用必须记录原因。
- 启用同一 `ruleCode` 新修订时，按固定锁顺序在同一事务自动停用旧修订并启用目标修订，同时递增version和写审计；任意异常整体回滚，不留下双版本启用状态。
- 新增 `POST /api/v1/staff/triage-rules/test`：WEB管理员和医生可按物种、文本及筛查答案预览全部适用的已批准且已启用规则，复用生产 `TriageEvaluator`，不写 `triage_event`、审计或报表数据。
- 新增受控文本解释器，区分明确发生、否定、假设、已结束历史和未知；只提取规则实际引用的封闭症状/时长代码。超出一年上限的异常时长降为UNKNOWN，不触发服务端错误。
- 三个操作已纳入严格OpenAPI schema与Spring运行时契约；enable/disable要求ADMIN，test要求ADMIN或DOCTOR。
