# M10-03 急症规则提交审核与医生审核验收记录

日期：2026-11-03。结论：通过。

## 已实现范围

- 新增 `POST /api/v1/staff/triage-rules/{ruleId}/submit-review`：仅WEB管理员可提交DRAFT规则，校验version并在行锁内重新验证predicate、物种、标题、风险、固定建议及HTTPS来源，进入IN_REVIEW后冻结正文。
- 新增 `POST /api/v1/staff/triage-rules/{ruleId}/review`：仅具有WEB DOCTOR角色且`doctor_profile.status=ACTIVE`的医生可审核；只接受APPROVE/REJECT，驳回必须填写500字以内备注。
- 审核仅允许IN_REVIEW状态，提交与审核均要求 `Idempotency-Key`，使用version乐观锁、状态条件更新和事务审计；相同请求可重放原响应，不同请求复用键会冲突。审核记录保存医生用户ID、备注和时间，未审核规则不会伪造审核身份。
- REJECTED规则仍可由管理员修改，修改后回DRAFT并清除旧审核信息，可再次提交；APPROVED规则继续由M10-02正文冻结保护拒绝原地PATCH。
- Security配置分别限制提交为ADMIN、审核为DOCTOR；OpenAPI使用专用严格请求schema，两个动作返回完整规则视图。
