## 已实现范围

- MINI 主人查询本人预约列表与详情。WEB 有效医生查询本人预约，WEB 管理员查询全院预约。跨范围详情和轨迹统一返回 `APPOINTMENT_NOT_FOUND`。
- 列表按创建时间、数值 ID 降序稳定分页。WEB 支持状态、宠物 ID 和医院 Asia/Shanghai 安排日期过滤。
