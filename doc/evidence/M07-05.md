# M07-05 双方取消和待确认超时验收记录

日期 2026-11-09。结论通过。

## 已实现范围

- MINI 主人、对应 WEB 医生和 WEB 管理员可在各自范围内取消预约。请求带 version、幂等键和原因，主人只可在开始前取消 PENDING 或 CONFIRMED 预约。
- 手动取消和 SYSTEM 超时使用同一状态机及事务锁序，原子释放一次名额，保留已存在的确认时间，记录取消来源、轨迹和审计，关闭 OPEN 改期并向双方发送站内通知。
- 定时任务默认每30秒查询最多100条到期待确认预约，逐单加锁复核。重复扫描没有重复副作用。可用 `appointment.timeout-scan.enabled` 和 `appointment.timeout-scan.interval-ms` 控制。
- M0705IT 核验定时任务注册，并直接调用同一扫描方法以确定性验证重复处理和数据库结果。
