# M05-05 健康日志修订验收记录

日期：2026-11-03。结论：通过。

## 已实现范围

- 实现`PATCH /api/v1/pets/{petId}/health-logs/{logId}`；只允许MINI当前主人修订本人宠物的主人自述日志，医生WEB会话无权修改。
- 修订先锁定ACTIVE宠物，再锁定目标日志并校验`version`；同版本并发请求只有一个成功，成功后版本递增，过期请求返回409。
- 严格校验观察时间、正体重、文本长度和至少一个健康内容；更新DTO不接受owner、诊断或来源等服务端/临床字段。
- 成功修订在同一事务内记录`HEALTH_LOG_UPDATE`审计，保存改前与改后快照，旧内容可追溯但不复制成第二条业务日志。
- 可变`HEALTH_LOG`附件采用整组替换；解绑不会删除文件，也不会移除`MEDICAL_VERSION`等临床历史绑定，附件越权时日志、审计和绑定全部回滚。
- OpenAPI将修订操作标为IMPLEMENTED，新增严格更新输入schema并同步生成Web和小程序类型。
