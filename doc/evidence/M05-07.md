# M05-07 健康时间线聚合验收记录

日期 2026-11-09。结论通过。

## 已实现范围

- `GET /api/v1/pets/{petId}/timeline` 复用对象授权，仅当前 MINI 主人可以查询，归档宠物历史仍可读取。非主人返回 `PET_NOT_FOUND`。
- LOG 使用观察时间和主人自述摘要，MEDICAL 使用提交时间和诊断节选，AI 使用会话创建时间和标题，APPOINTMENT 使用当前预约安排时间和状态。正式病历按 SUBMITTED 过滤，且校验关联预约的宠物、医生和用户归属。
- 默认返回全部类别，可用 `type` 过滤，`pageSize` 为 1–100。按 UTC 业务时间、数值 ID、类型降序，支持毫秒边界和跨表同 ID。游标绑定宠物和分类，末页 `nextCursor=null`。排序键发生编辑时，刷新首屏可读取新位置。
- 使用真实 MySQL 已迁移表的固定数据构造病历、AI 会话和预约。用例覆盖主人隔离、WEB/匿名拒绝、草稿和外部归属数据隔离、四类摘要、分类过滤、无效游标与逐条翻页。
