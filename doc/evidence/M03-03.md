## 实际改动

- `server/pom.xml`：加入Boot管理的`spring-boot-starter-oauth2-resource-server`；实际解析Spring Security Resource Server/JOSE 6.5.11和Nimbus JOSE JWT 9.37.4。

- `identity/Rs256AccessTokenIssuer.java`：M03-01手写JCA JWT迁移到Nimbus签发，保留`sub/userId/sessionId/tokenVersion/aud/roles/iat/exp/jti`声明。
- `identity/SessionJwtValidator.java`：逐请求查询`auth_session JOIN sys_user`，核对session所属用户和客户端、未撤销、未过期、账号ACTIVE、tokenVersion一致；数据库不可用时安全失败。
- `identity/CurrentIdentity.java`、`CurrentIdentityProvider.java`：提供强类型当前身份、客户端和角色/权限上下文。
- `shared/SecurityConfig.java`：精确公开白名单；`/staff/**`、`/admin/**`要求`AUD_WEB`，用户业务前缀要求`AUD_MINI`；认证失败和权限不足分别返回统一401/403 Envelope，响应禁用缓存。
- `tools/generate-jwt-key.ps1`、`.gitignore`、`application.yml`、`.env.example`、`README.md`：本地持久RSA密钥生成、外部PEM配置和运维边界。脚本发现任一目标已存在即拒绝覆盖；`.local/`不跟踪，密钥未写日志或证据。

- `M0303IT.java`：测试专用身份探针由IT导入，不进入生产Controller或冻结OpenAPI。

## 行为与安全断言

1. 合法MINI/WEB token通过Nimbus RS256验签并建立`CurrentIdentity`；roles映射为`ROLE_*`，audience映射为`AUD_MINI`/`AUD_WEB`。
2. 合法token访问错误客户端路由返回统一403 `FORBIDDEN`；不会把MINI身份用于后台或把WEB身份用于用户业务。
3. 过期、错误session audience、错误issuer、伪造签名均返回统一401；过期使用`TOKEN_EXPIRED`，其余无效认证使用`UNAUTHENTICATED`。
4. session已撤销、session已过期、账号停用、tokenVersion不一致均由真实MySQL状态立即使access token失效并返回401。
5. `GET /api/v1/hospital`、健康/OpenAPI及三个认证POST是精确公开入口；`/hospital/...`子路径不会因通配而公开。
6. 没有用H2、空测试、mock数据库或跳过测试替代会话与撤销验收。
