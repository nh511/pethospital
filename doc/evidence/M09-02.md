- 新增 `POST /api/v1/staff/health/guides/{guideId}/publish` 与 `offline`，只允许 WEB 管理员，要求 `Idempotency-Key` 和乐观锁 version。

- 下架只接受 PUBLISHED，原因必填并写入审计；保留历史 `publishedAt`，以状态即时阻止后续公开读取。

- 发布/下架使用全局幂等事务，重放不重复递增 version 或追加审计；发布不会创建知识文档、版本、分块或索引任务，不自动进入 RAG。
