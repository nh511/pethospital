# M05-03 宠物归档验收记录

日期：2026-11-03。结论：通过。

## 已实现范围

- `POST /api/v1/pets/{petId}/archive`只允许MINI audience的当前主人操作，使用严格请求DTO、version和`Idempotency-Key`；成功返回归档状态与新版本并留下`PET_ARCHIVE`事务审计。
- `ActivePetGuard`在现有事务中对主人宠物执行`SELECT ... FOR UPDATE`并校验ACTIVE，作为归档以及后续预约/问诊创建共用的锁入口。
- 归档按固定顺序锁宠物、未终结预约和处理中AI消息；PENDING/CONFIRMED/IN_CONSULTATION预约或QUEUED/PROCESSING消息存在时返回409及分类数量。
- 归档仅更新pet状态和version，不删除健康日志、预约、病历或AI历史；归档后详情仍可读取，新的业务写入通过共享ACTIVE守卫拒绝。
- OpenAPI将归档操作标为IMPLEMENTED，并新增严格的归档输入、结果和响应schema，同步生成Web和小程序类型。
