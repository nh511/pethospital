# M06-06 医生启停与前置检查验收记录

日期：2026-11-02。结论：通过。医生资料启停、未终结预约保护和旧会话临床权限收缩已在真实 MySQL 8.4.13 上验证。

## 实现范围

- 新增 `POST /api/v1/admin/doctors/{doctorId}/disable` 与 `enable`，要求 WEB audience、管理员身份、`admin:doctors:manage` 权限、`Idempotency-Key` 和乐观锁 version。
- 停用按 doctor profile、未终结预约的固定锁顺序执行；存在 `PENDING_CONFIRMATION`、`CONFIRMED`、`PROCESSING` 或 `RESCHEDULE_REQUESTED` 预约时返回 409，并在错误数据中给出待处理数量。
- 停用成功后医生资料变为 `DISABLED`；公开医生与可预约时段查询即时隐藏。时段关闭与预约处理仍是显式独立动作，停用不会静默取消预约或篡改占用。
- 启用前重新校验关联账号和 ACTIVE DOCTOR 角色，避免只恢复资料状态而放出无效医生。
- 旧医生会话不被伪报为已撤销，但临床对象授权不再给出 doctorId，排班写入口也拒绝非 ACTIVE 医生资料，因此无法继续产生新的临床写入。
